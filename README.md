AK Foundation website, built with [Next.js](https://nextjs.org).

AK Foundation is a non-profit organization in Markham, Ontario, Canada. The
organization runs a music performance studio called Aayakalaihal Arangam,
located at 80 Travail Road in Markham.

## Getting Started

First, run the development server:

```bash
npm run dev
```
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the
result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
